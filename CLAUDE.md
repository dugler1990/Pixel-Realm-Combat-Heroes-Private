# Notes for agents

Several agents work on this repo at the same time, often in this one folder. A folder has one
checked-out branch, so switching branches here moves every agent in it.

- Don't `git switch` or `git checkout` in a folder another agent may be using; ask the user first.
- To work on a branch in its own folder, follow [docs/WORKTREES.md](docs/WORKTREES.md).
